# JELAS · Jelajah Kelas (versi online)

Aplikasi belajar TK–SMA/SMK. Situs ini diterbitkan otomatis oleh GitHub Pages setiap ada perubahan.

| File | Isi |
|---|---|
| `index.html` | Aplikasi |
| `config.js` | Kode Firebase proyek |
| `firestore.rules` | Aturan keamanan database. Tempel di Firebase Console → Firestore Database → Aturan |
| `manifest.webmanifest`, `sw.js`, `icons/` | Supaya bisa dipasang sebagai aplikasi Android |
| `privacy.html` | Kebijakan privasi untuk Play Store |

## Peran
- **Murid:** daftar sendiri dengan nama pengguna dan sandi 4 angka. Gratis.
- **Guru:** daftar dengan email. Paket Gratis: 1 kelas, maksimal 10 murid, dasbor, dan kode kelas. Paket Pro membuka Absensi, Evaluasi TV, Soal, Rapor, dan murid tanpa batas.
- **Admin:** akun guru dengan email admin yang sudah diverifikasi. Admin mengaktifkan Pro, mengatur nomor WhatsApp, harga, dan pengumuman.
