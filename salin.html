Pasang pembaruan JELAS

1Aturan Firebase WAJIB

Buka Firebase ↗
  1. Tekan tombol hijau Salin.
  2. Tekan Buka Firebase, lalu masuk dengan akun Google-mu.
  3. Tekan lama di kotak kode, pilih Pilih semua, lalu Tempel.
  4. Tekan Publikasikan (Publish).

2Kode server NANTI SAJA

Hanya untuk notifikasi colekan dan pengikut baru di HP. Lebih nyaman dikerjakan di laptop. Buka Cloudflare ↗
  1. Tekan tombol hijau Salin.
  2. Tekan Buka Cloudflare, lalu Edit code.
  3. Pilih semua kode lama, lalu Tempel.
  4. Tekan Deploy.
